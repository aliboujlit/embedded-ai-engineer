# EMBEDDED AI ENGINEER (EAI)

**EMBEDDED AI ENGINEER** est un programme de développement logiciel destiné à créer une plateforme d'ingénierie électronique et de systèmes embarqués assistée par intelligence artificielle locale.

## 🎯 Objectif

Transformer une idée, un besoin ou un cahier des charges en un **dossier technique complet, vérifiable et exploitable** pour la réalisation physique d'un produit électronique (*Engineering Realization Package — ERP*).

## 🏛️ Architecture

- **EAI Core** : orchestration, gestion de projet, base de données, audit.
- **AI Engine** : LLM local, Model Manager, agents spécialisés.
- **Integration Hub** : adaptateurs EDA, MCU, simulateurs, tests.
- **Desktop** : interface Windows (PyQt6).
